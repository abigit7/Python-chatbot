# 🤖 Liz - Flask Chatbot

## 🌟 Overview
Liz is a simple chatbot built using **Python** and **Flask**. It provides automated responses to user queries, demonstrating the basics of chatbot functionality with Flask as the backend. 🚀

## 🔥 Features
- 💬 Handles basic user queries
- 🌐 Runs on a Flask web server
- 🎨 Simple and lightweight architecture

## 🎯 Usage
- Ask anything!!
- The chatbot will respond based on predefined logic.

## 🛠 Technologies Used
- 🐍 Python
- 🌐 Flask
